Configuração Evolution API

Como configurar? (passo a passo)

1. Crie um novo serviço no Railway

No painel do Railway → New Service → Docker Image → cole:

atendai/evolution-api:latest

2. Adicione as variáveis no serviço Evolution API:

AUTHENTICATION_TYPEapikey
AUTHENTICATION_API_KEYcrie uma chave forte (ex: MinhaChave123!)
DATABASE_ENABLEDtrue
DATABASE_CONNECTION_URIsua URL do Supabase (mesma que usa aqui)
DATABASE_CONNECTION_DB_PREFIX_NAMEevolution

3. Copie a URL pública do serviço Evolution API

Ex: https://evolution-api-production-xxxx.up.railway.app

4. No seu app principal, adicione as variáveis:

WEBHOOK_WHATSAPPURL do Evolution API acima
EVOLUTION_INSTANCEnome da instância (ex: meu-negocio)
EVOLUTION_API_KEYa chave que você criou no passo 2

5. Volte aqui e escaneie o QR Code

Após salvar as variáveis, o Railway vai reiniciar. Volte nesta página e clique em Atualizar.
